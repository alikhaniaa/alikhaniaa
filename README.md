# Alireza Alikhani

MSc student in AI and Robotics (Khatam University, Tehran) with a BSc in cellular and molecular biology, and a software developer with Java backend and full-stack web experience. I want to build research software for biology: tools that are tested, documented and fast enough for real data.

## Research software and research projects

- [kmer-sketch](https://github.com/alikhaniaa/kmer-sketch) (Rust): canonical k-mer counting, FracMinHash sketching, sketch comparison (Jaccard, containment, Mash distance), read-set simulation from reference genomes and clustering of simulated "cells" by species. Checked against an independent Python implementation; tests, benchmarks and failure cases are in the README.
- [sparsepack](https://github.com/alikhaniaa/sparsepack) (Rust): library and command-line tool for a compressed, block-indexed file format for sparse integer matrices: delta and varint coding, per-block checksums, random access by row range, parallel filtering and column sums. Byte-level format description, tests and benchmarks with their limits.
- [streaming-local-credit](https://github.com/alikhaniaa/streaming-local-credit) (Python): streaming actor-critic (batch size 1, no replay) on four MuJoCo tasks, with hidden layers trained by local feedback rules. Per-seed results, tables and commands to reproduce them.
- [ghostwave](https://github.com/alikhaniaa/ghostwave) (C++): electric-field model of a weakly electric fish, with tests and a physics write-up with references, plus a small game built on it.
- [data-hub](https://github.com/alikhaniaa/data-hub) (Python): collects public market data into Parquet files with incremental updates, atomic writes and per-collector lock files.

I did rodent stereotaxic surgery and behaviour at INCAS, and I am setting up a songbird electrophysiology lab at IPM (ongoing).
