# Alireza Alikhani

MSc student in AI and Robotics (Khatam University, Tehran), with a BSc in cellular and molecular biology. I work on how networks learn with local signals and how they stay able to learn over long task streams. Before that I did rodent stereotaxic surgery and behaviour at INCAS and set up a songbird electrophysiology lab at IPM, and I worked as a Java backend developer.

## Repositories

- [streaming-local-credit](https://github.com/alikhaniaa/streaming-local-credit): streaming actor-critic (batch size 1, no replay) on four MuJoCo tasks, with hidden layers trained by local feedback rules. Per-seed results, tables and commands to reproduce them.
- [kmer-sketch](https://github.com/alikhaniaa/kmer-sketch): a small Rust tool for k-mer counting and FracMinHash sketching, with a simulated single-cell bacterial data set. Tests, benchmarks and failure cases are in the README.
- [ghostwave](https://github.com/alikhaniaa/ghostwave): C++ electric-field model of a weakly electric fish, with tests and a physics write-up with references, plus a small game built on it.
- [data-hub](https://github.com/alikhaniaa/data-hub): Python toolkit that collects public market data into Parquet files with incremental updates.
